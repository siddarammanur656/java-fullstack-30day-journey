☕ Java Full-Stack Developer Journey

This repository documents my **30-Day Java Full-Stack Developer Learning Journey**.  
Each day I practice Java concepts, explore backend technologies, and build small projects to strengthen my programming skills.

The goal of this journey is to gain strong knowledge in **Java, Spring Boot, REST APIs, databases, and frontend technologies** required for modern full-stack development.

By the end of this journey, I aim to build real-world projects and develop the skills required to become a **Java Full-Stack Developer**.

Goal: Become a Java Full-Stack Developer by building real backend and frontend applications.

---

Day 1: Java Basics
- Installed JDK 17 and set up the development environment
- Configured IDE for Java development
- Created and executed the first Java program (Hello World)
- Learned Java data types and variables
- Practiced arithmetic, comparison, and logical operators
- Explored implicit and explicit type casting
- Practiced common String methods such as length(), toUpperCase(), and substring()
- Built a CLI Calculator using Scanner and switch case

Day 2: Control Flow and Arrays
- Learned conditional statements using if, else if, and switch
- Practiced loops including for loop, while loop, and enhanced for loop
- Understood how loops help automate repetitive tasks
- Learned about arrays and how to store multiple values in a single variable
- Explored ArrayList for dynamic data storage
- Practiced iterating through arrays and ArrayLists using loops
- Built a Student Grade Tracker CLI application that accepts marks and calculates average and grade

Day 3: Methods and Recursion
- Learned how to define and call methods in Java
- Understood method parameters vs arguments
- Explored how the call stack works when a method is executed
- Learned the concept of pass-by-value for primitives and reference types
- Practiced method overloading and how Java resolves overloaded methods
- Implemented recursive methods with proper base cases and recursive calls
- Studied recursion performance using the Fibonacci example
- Learned optimization using memoization
- Practiced several useful methods from the Java Math class
- Built utility programs including **MathUtils** and a **Number Guessing Game**

Day 4: Object-Oriented Programming (OOP)
- Learned the core philosophy of Object-Oriented Programming and why it is used in modern software development
- Studied classes and objects and understood how objects represent real-world entities in code
- Explored how objects are stored in memory and how classes act as blueprints
- Learned different types of constructors including default, parameterized, and constructor chaining
- Practiced encapsulation by protecting class data using private fields with getters and setters
- Understood the `this` keyword and its common uses inside class methods and constructors
- Learned the purpose of `toString()`, `equals()`, and `hashCode()` methods
- Compared static members and instance members and when to use each
- Built a **Bank Account System** project implementing classes, constructors, and encapsulation
